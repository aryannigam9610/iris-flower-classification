# 🌸 Iris Flower Classification Using Machine Learning

An end-to-end Machine Learning project that classifies Iris flowers into three different species (*Setosa, Versicolor, and Virginica*) based on their sepal and petal measurements.

## 📌 Project Overview
The Iris flower dataset is a classic dataset in machine learning and statistics. This project uses classification techniques to identify the species of an Iris flower based on four features:
1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width

## ✨ Features
* **Exploratory Data Analysis (EDA):** Beautiful pair plots and heatmaps to understand feature relationships.
* **Data Preprocessing:** Standardizing features for better model performance.
* **Multi-Class Classification:** Implementation of popular algorithms like Logistic Regression, Decision Trees, and Support Vector Machines (SVM).
* **Model Evaluation:** Detailed breakdown using Confusion Matrix and Classification Report.
